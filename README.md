# Snake

A Snake game I made with Python and Pygame. Eat apples to grow and avoid hitting
the walls or yourself. The game has a green checkerboard, a blue snake, background
music, and settings for map size and speed. It also tracks fruit eaten and time alive.

## Instructions for Build and Use

Steps to run the game:

1. Install Python and open a terminal in the project folder.
2. Install Pygame with `python -m pip install pygame==2.6.1`.
3. Run `python main.py`.

Instructions for using the software:

1. Click Settings to choose a map size and speed, then click Done.
2. Click Start and use the arrow keys to move. Each apple adds one point.
3. Click Play Again after a round ends.
